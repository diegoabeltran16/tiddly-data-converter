# Alcance de licencia de TDC

Este alcance comprende el código fuente, tooling, automatizaciones, pruebas de software y documentación operativa first-party que forman parte de TDC y acompañan su desarrollo, distribución u operación, salvo que una superficie indique expresamente una licencia diferente.

Las dependencias, componentes, referencias, assets y demás materiales de terceros conservan sus respectivas licencias, avisos, atribuciones y condiciones.
La licencia del software TDC no modifica por sí misma la titularidad ni las condiciones de licencia del contenido, datos o conocimiento procesado, almacenado, administrado o producido mediante TDC. Esto incluye, entre otros, Canon, tiddlers de usuarios, documentos importados, archivos de usuarios, embeddings, chunks, grafos, datasets, modelos, outputs y otros derivados de contenido.

La disponibilidad de una modificación de TDC bajo esta licencia no implica su aceptación en el upstream oficial del proyecto. La integración en `main` continúa sujeta a revisión, pruebas, compatibilidad, gobernanza y autoridad de mantenimiento.
